Security Endorsement Program

Endorsement Criteria & Testing Standards
Important Disclaimer: A Redline endorsement is a voluntary, performance-based recognition granted to websites that pass our simulation-based tests. It does not constitute a formal security audit, regulatory certification, or guarantee of protection. We are not a penetration-testing service, nor do we certify compliance with any governmental or industry-specific standard.
Testing criteria for endorsement
Performance & Availability
  • Survives a burst of rapid requests
  • Responsive average load time
  • Rate limiting on rapid traffic
Transport & Browser Protection
  • Valid HTTPS with HTTP→HTTPS redirect
  • Core security headers configured
  • Clickjacking & secure-cookie protection
Injection & Input Handling
  • No reflected SQL errors
  • No reflected XSS payloads
  • No open-redirect behaviour
Access & API Surface
  • No exposed sensitive paths
  • Safe CORS configuration
  • CSRF protection on forms
Overall: a site must pass every selected test with zero failures to earn the endorsement. Endorsement reflects the result at the time of testing and can be revoked if the site no longer passes.
