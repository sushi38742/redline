Domain Verification

To prevent abuse, you must verify domain ownership by adding this meta tag to your website's <head> section: 

<meta name="breakmysite" content="verified">

General Steps:

  1. Access your website's HTML files (via FTP, hosting panel, or code editor)
  2. Find your main HTML file (usually index.html or similar)
  3. Locate the <head> section (between <head> and </head> tags)
  4. Add the meta tag anywhere inside the <head> section
  5. Save and upload the file to your web server

Platform-Specific Instructions:

WordPress
  1. Go to Appearance → Theme Editor
  2. Select header.php
  3. Add the meta tag in the <head> section
  4. Update file
HTML/Static Sites
  1. Open your index.html file
  2. Find the <head> section
  3. Add the meta tag
  4. Save and upload to your server
React/Vue/Angular
  1. Open public/index.html
  2. Add meta tag in <head>
  3. Rebuild and deploy your app
Hosting Panels
  1. Log into cPanel/hosting dashboard
  2. Use File Manager
  3. Navigate to public_html
  4. Edit your main HTML file

Example: Your <head> section should look like this:

<head>
  <meta charset="UTF-8">
  <title>My Website</title>
  <meta name="breakmysite" content="verified">
  <!-- other meta tags and styles -->
</head>
